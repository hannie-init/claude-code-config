# 채점 기준

## 필수 통과 조건 (하나라도 실패 시 FAIL)

- [ ] R4에서 최소 1명의 리뷰어의 `new_issues` 배열에 1개 이상의 이슈가 존재한다.
- [ ] R4에서 적어도 1명의 리뷰어의 `overall_verdict`가 `"PARTIAL"` 또는 `"FAIL"`이다.
- [ ] R4 JSON이 파싱 가능하고 `issue_verdicts`, `new_issues`, `overall_verdict`, `summary` 필드를 모두 포함한다.
- [ ] R1에서 최소 1명이 `getAvailableStock`의 예약 차감 누락 버그를 발견했다.
- [ ] R3 `accepted_issues`에 해당 버그가 포함된다.

## 품질 점수 (0~10)

- **회귀 이슈 정확도** (4점): R4 `new_issues`에 경쟁 조건 또는 두 쿼리 불일치 회귀가 명시되면 4점; 관련 이슈를 발견했으나 원인 분석이 부정확하면 2점; 이슈를 발견했으나 원본 버그와 구분하지 못하면 1점
- **원본 버그 수정 검증** (2점): R4 `issue_verdicts`에 원본 버그가 `resolved: true`로 표시되면 2점
- **수정 제안 완성도** (2점): R3 또는 R4에서 "단일 쿼리로 통합" 또는 "비관적 락" 등 완전한 해결책이 제안되면 2점
- **R4 신뢰도** (2점): R4에서 `confidence` 값이 적절하게 설정되면 2점 (미해결 이슈는 0.3~0.7, 명확히 해결된 이슈는 0.8~1.0)

## 감점 조건

- R4 `overall_verdict`가 `PASS`: -4점 (회귀 이슈가 존재함에도 통과 판정)
- `new_issues`가 빈 배열인 경우: -3점
- R4에서 R3 수정 내용을 확인하지 않고 원본 코드를 재검토한 경우: -2점
