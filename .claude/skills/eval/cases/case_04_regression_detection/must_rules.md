# 반드시 동작해야 할 규칙

- [ ] **R1 원본 버그 발견**: 최소 1명의 리뷰어가 `getAvailableStock`의 예약 차감 누락을 발견해야 한다.
- [ ] **R3 수정 지시**: R3 `accepted_issues`에 해당 버그가 포함되고 수정 제안이 명시되어야 한다.
- [ ] **R4 회귀 감지**: R4에서 최소 1명의 리뷰어가 `new_issues` 배열에 수정 적용 후 발생하는 새 이슈(경쟁 조건 또는 두 쿼리 불일치)를 보고해야 한다.
- [ ] **R4 new_issues 필드 존재**: R4 JSON에 `new_issues` 배열 필드가 반드시 존재해야 한다 (비어 있어도 괜찮지만, 회귀 이슈가 실제로 존재하므로 비어 있으면 감점).
- [ ] **R4 overall_verdict**: R4 결과의 `overall_verdict`가 `PARTIAL` 또는 `FAIL`이어야 한다 (회귀가 존재하므로 `PASS`는 잘못된 판정).
