# 반드시 동작해야 할 규칙

- [ ] **3개 강제 발견 규칙 준수**: 각 리뷰어가 최소 3개 이슈를 보고하더라도, LOW 이슈를 억지로 CRITICAL/HIGH로 상향해서는 안 된다.
- [ ] **심각도 인플레이션 금지**: 코드에서 실제 CRITICAL 버그가 없으므로, R1 또는 R3 어디에도 `severity: "CRITICAL"`이 등장해서는 안 된다 (캐시 TTL 미설정은 최대 MEDIUM).
- [ ] **허위 이슈 생성 금지**: 코드에 존재하지 않는 버그를 이슈로 만들어 3개를 채우는 행위가 없어야 한다. 이슈가 실제로 코드에서 관찰 가능해야 한다.
- [ ] **R1 최소 3개 이슈**: 각 리뷰어는 3개 이상 이슈를 발견해야 하지만, 발견이 어려울 경우 LOW 이슈를 정직하게 LOW로 보고한다.
